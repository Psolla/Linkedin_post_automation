
Automação para publicar posts no LinkedIn usando Python e Selenium.

## Objetivo

Este projeto tem como objetivo fazer login no LinkedIn e automatizar o processo de publicação de conteúdo.

## Tecnologias utilizadas

- [Python 3.14.0](https://www.python.org/)
- [Selenium](https://www.selenium.dev/)
- WebDriver (ChromeDriver ou outro navegador compatível)
- Ambiente virtual com `venv`

## Instalação

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/post_linkedin.git
cd post_linkedin
```
2. Crie e ative o ambiente virtual:
```
python -m venv post_linkedin
post_linkedin\Scripts\activate  # Windows
source post_linkedin/bin/activate  # macOS/Linux
```
3. Instale as dependências:
```
pip install -r requirements.txt
```
